# Route Planner (Reittisuunnittelija)

Tämä on Python (Flask) ja JavaScript (Leaflet.js) pohjainen reittisuunnittelija, joka laskee pysäkkien väliset etäisyydet ja optimoi reitin järjestyksen.

## Asennus ja suoritus

1. Luonto ja aktivoi virtuaaliympäristö:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

2. Asenna riippuvuudet:
   ```bash
   pip install -r requirements.txt
   ```

3. Käynnistä sovellus:
   ```bash
   python3 src/app.py
   ```

4. Avaa selaimessa: `http://localhost:5000`
